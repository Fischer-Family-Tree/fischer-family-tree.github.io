# Fischer Family Tree

The family website for the descendants recorded in the Nölting and Ehlers family books.
Everything here is locked with the family password: names, dates and book pages can only be read in the browser after the password is entered.

- `index.html` — the website
- `*.enc`, `pages/*.enc` — the locked family records and book page scans
- `source/` — the files the site is built from (no family data)

Ask Chris for the family password.
